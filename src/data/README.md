# 数据文件说明

| 文件 | 用途 | 使用位置 |
|---|---|---|
| `siteData.json` | 站名、描述、OG 图、官方社交账号 | SEO、页脚、首页/防诈骗页的官方账号卡 |
| `nav.json` | 导航与页脚链接 | `Navbar.astro`、`Footer.astro` |
| `pillars.json` | 首页「我分享什么」卡片 | `pages/index.astro` |
| `verifySteps.json` | 首页「辨别真假 Spark」手风琴 | `pages/index.astro` |
| `partners.json` | 官方合作伙伴 | 首页、`/partners` |
| `videos.json` | 内容中心的 YouTube 视频 | `lib/content.ts` |
